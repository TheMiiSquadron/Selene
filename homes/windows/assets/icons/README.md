# Reicon assets

The SVG files in this directory are locally bundled outline icons from
[Reicon](https://reicon.dev/icons). They were selected from the upstream
`newicons` category on October 12, 2026.

Included upstream icon names:

- `message-add2`
- `search-normal2`
- `folder2`
- `monitor3`
- `setting2`
- `sidebar-left2`
- `message3`

Reicon is distributed under the MIT License. The upstream license notice is
preserved in `LICENSE.reicon.txt`. The icons are bundled locally so Windows
Home does not make runtime network requests or require an icon package.
